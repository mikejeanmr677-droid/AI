添加平台

🔑 浏览器抓取型无需 API Key。首次使用需先登录一次：双击项目目录的 重新登录.bat（或执行 node scripts/wallet-login.mjs），脚本会自动列出所有「浏览器抓取型」平台逐个登录（新添加的平台也会自动包含）。登录成功后保存平台，之后定时巡检自动抓取余额。
⚠️ 余额查询 URL 请填写该平台的钱包余额页面网址（余额显示在哪一页就填哪一页），抓取关键词对应页面上余额旁边的文字。

充值提醒

使用说明：系统每小时自动抓取各 AI 平台钱包余额，余额低于阈值（默认 200）时，自动生成充值提醒并发通知（邮件 / 桌面弹窗 / 手机推送）。
操作流程：你实际充值成功后，在对应提醒上点「登记打款」——之后每次巡检会自动检测该平台余额是否上涨，确认到账后自动累计到「资金统计」并记账，无需逐个操作。
按钮含义：「立即巡检」= 手动立刻执行一轮检查（不用等每小时）；「检测到账」= 手动单独验证某一单是否已到账；「撤销打款」= 误点登记后改回原状态；「备注」= 记录这笔用途。
